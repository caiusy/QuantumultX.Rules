# QuantumultX.Rules

个人使用的 Quantumult X 重写规则镜像。

## 订阅地址

```text
https://raw.githubusercontent.com/caiusy/QuantumultX.Rules/main/rewrite/unlock.conf
```

## 调整说明

- 基于 [tinyrepo/QuantumultX.Rules](https://github.com/tinyrepo/QuantumultX.Rules) 的 `rewrite/unlock.conf` 整理。
- 已将配置引用的全部 55 个 JavaScript 脚本镜像到本仓库 `rewrite/js/`。
- 已把配置内所有 JavaScript 地址改为本仓库的 Raw 地址。
- 已从 MITM `hostname` 中移除 `ios.chat.openai.com`，避免对 ChatGPT 流量进行中间人解密。
